What is a vector?

A scalar has magnitude only (speed = 60 mph). A vector has both magnitude and direction (velocity = 60 mph north). Trig is the tool that lets us work with direction — decomposing vectors into components and reassembling them.

Adding vectors — the component method

To add two vectors, break each into x and y components using trig, add the matching components, then use the Pythagorean theorem to find the resultant magnitude and arctan to find its angle.

The dot product — trig in disguise

The dot product tells you how much two vectors point in the same direction. It uses cosine, because cosine measures alignment. When θ = 0° vectors are perfectly aligned; when θ = 90° they are perpendicular and the dot product is zero.

A · B = |A| |B| cos θ
A · B = Ax·Bx + Ay·By   (component form — same result)
